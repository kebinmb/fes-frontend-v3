# Version Control Guide

This frontend repo should be versioned together with the backend repo at:

`C:\Users\jkmor\Documents\git\fes`

## Suggested Baseline

- Frontend: `frontend-v0.1.0`
- Backend: `backend-v0.1.0`
- Coordinated release: `fes-v0.1.0`

## Before Tagging

1. Run the frontend build.
2. Run backend tests.
3. Check that service methods match backend endpoints used by the UI.
4. Update this repo's `CHANGELOG.md`.
5. Update the backend repo's `CHANGELOG.md` and integration docs.
